# Hirst Dot Painting (Python Turtle)

A simple Python project inspired by Damien Hirst's dot paintings.

This project was built using the `turtle` module and random RGB colors.

---

## Features

- 10x10 dot grid
- Random RGB colors
- Fast turtle drawing
- Clean spacing between dots
- Hidden turtle cursor

---

## What I practiced

- Nested loops
- Functions
- RGB color generation
- Turtle graphics
- Coordinate positioning with `goto()`
- Working with rows and columns
- Randomization with `random`

---

```
main.py
```

## How to run

Make sure Python is installed.

Run:

```bash
python main.py
```
